## 修复清单

|问题与影响|修复结果|
|---|---|
|永久删除只提示“已提交”，后台删除完成后列表仍保留 Agent，容易重复操作|删除弹窗等待异步任务终态，显示进度/失败，成功后刷新目录|
|刷新丢失所选功能页，服务器入口不直接打开设置|页签写入 URL，支持浏览器历史；连接入口直达设置；窄屏自动滚动到活动页签|
|未保存编辑关闭后丢失，弹窗键盘定位不便|取消、关闭、Escape 和应用内导航确认丢弃；增加离页提醒、焦点约束/恢复及按钮名称|
|新建资源与现有 ID 冲突可能覆盖原资源|新增重复 ID 校验，保留表单并明确提示编辑已有资源或更换 ID|
|重复点击、轮询重叠、旧搜索请求晚返回导致状态不可靠|关键操作互斥，保存中禁用按钮；请求序号阻止旧响应覆盖；后台页减少轮询|
|网络失败及结构化校验错误难理解|统一中文网络/超时提示，解析字段错误，保留输入；请求总超时 130 秒，不自动重试写操作|
|模型测试失败仍可能出现成功提示|按 ok 字段区分结果；诊断区明确显示通过/失败，原始数据折叠|
|历史恢复容易误操作|增加恢复确认，当前版本及执行中的操作禁用|
|空列表显示 1–0/0，状态与时间不便阅读|改为 0–0/0，加入清空筛选，翻译常见任务/沙箱状态和任务类型，格式化时间|
|恢复重试间隔缺乏输入检查|限制 1–10 个整数，每个 1–3600 秒，兼容中文逗号，保存中禁用提交|
|能力探测失败无直接恢复路径|明确显示错误并提供重试检测|
|导入切换文件可能保留旧预览，超大文件到服务端才失败|清理旧结果并增加本地 20 MiB 文件检查|
|macOS 页面显示无法兑现的 Windows 凭据保存选项|由本地服务返回平台能力，隐藏不支持的选项，说明凭据仅保存在当前进程|
|任务诊断需猜测原始字段|任务详情展示阶段、时间、标识和关联调用链，打开后自动定位|
