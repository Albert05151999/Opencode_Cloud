# 配置导入与导出

入口：本地 Web → 管理 → 导入导出。配置包迁移模型、账户池、Skill、MCP、Hook 和 Agent 模板，不包含聊天记录、工作区或运行中的沙箱。

## 选择导出方式

| 方式 | 用途 | Key |
| --- | --- | --- |
| 导出资源配置 | 分享配置结构 | 结构化凭据脱敏，导入后补齐 |
| 加密资源包，勾选包含凭据 | 自己迁移服务器、预配置安装 | 至少 12 字符口令加密 |
| 导出原生 OpenCode 包 | 原生 OpenCode 使用指定 Agent | 不等同于平台完整恢复 |

Skill 附件保留原文，分享前检查其中是否手写了秘密。结构化字段脱敏不会改写附件。

## 导入已有平台

1. 选择文件；加密包先填写口令。
2. 查看预览，核对条目、缺失 Key、附件及同名冲突。
3. 选择条目；同名时改目标 ID 或明确勾选替换草稿，已有发布版本不变。
4. 导入草稿；这不会自动创建可调用 Agent。
5. 补齐并测试模型账户，发布模型网关和所需扩展资源。
6. 从待恢复模板选择 Agent，映射模型、资源版本，填写新的 Agent ID。
7. 恢复草稿，发布，再发起真实会话。

模型重命名时模板引用随导入映射更新。校验或冲突失败不会提交部分条目。只导入部分依赖时需补齐引用后才能发布。

也支持原生 OpenCode JSON/JSONC、单个 SKILL.md、Skill ZIP。粘贴填表见[模型配置](model-configuration.md)。

## 配置包预配置新部署

导出含凭据的加密包，放在构建机器，在根 .env 填写：

```dotenv
MINIMAX_API_KEY=
MINIMAX_API_KEY_2=
ZAI_API_KEY=
ZAI_API_KEY_2=
PRESET_AGENTS=
BOOTSTRAP_BUNDLE=我的配置.encrypted.json
BOOTSTRAP_PASSWORD=导出时使用的口令
```

路径相对仓库根目录，也可绝对路径。运行 `python3 build_image/build.py bundle` 将包带入私有归档。安装复用管理页面的解析校验接口，导入模型和资源，恢复每个 Agent 的草稿并发布。历史版本保留为模板，不为每个历史版本额外创建 Agent。

简单预设与配置包不能同时启用。普通脱敏包适合手动导入后补 Key，不适合无人值守恢复。

初始化记录完成阶段，重复安装不覆盖页面修改。更换初始化来源时，安装提示改用管理页面导入。

## 验证结果

核对模型数、账户数、Agent 默认模型、资源绑定版本；测试账户并发起会话。导入、发布、真实推理需分别确认。

需要保留聊天记录和工作区时，另外迁移运行数据。配置导出不能代替运行数据备份。
