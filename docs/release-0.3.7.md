# 0.3.7 部署验收记录

验收日期：2026-09-16。范围为默认 IP 部署、两个预设模型/Agent、本地 Windows 管理 Web，以及保留现有数据的远程升级。

## 清理

- 删除三个确认没有调用方的入口：`create_health_router`、`LoadTestStore.active_agent`、`AppConfig.safe_dict`，连同对应废弃导入。
- 清理前端未使用的图标导入、React 默认导入和旧导航图标数据。
- LiteLLM 的成功/失败日志回调由框架调用，保留。
- API 文档生成器移动到 `build_image/tools/build_api_reference.py`，不再放入网关服务源码目录。
- 本机和服务器各删除 21 个本项目旧镜像标签；服务器另清理一个已确认属于本项目的无标签旧镜像。保留新版 8 个镜像和其他项目镜像。
- 清理本地 54 个旧发布/镜像归档、服务器 12 个旧归档。保留运行数据，临时 Windows 挂载盘验收数据归档供排查。
